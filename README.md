# مؤسسه آموزشی کودک ماهر مانا

وب‌سایت مؤسسه آموزشی کودک ماهر مانا: Astro 7 (HTML ایستا و سریع) + Tailwind CSS 4، پنل مدیریت محتوا با Decap CMS، حرکت با CSS، GSAP (فقط صفحه‌ی مسیر) و Lottie.

## اجرا

Node `22.23.4` یا تازه‌تر (فایل `.nvmrc`؛ Astro 7 با نسخه‌ی قدیمی‌تر اجرا نمی‌شود):

```bash
npm ci
npm run dev      # http://localhost:4321
npm run build    # خروجی در dist/
npm run preview  # دیدن نسخه‌ی ساخته‌شده
npm run offline  # نسخه‌ی آفلاین در offline/ (index.html را مستقیم در مرورگر باز کنید)
```

## محتوا و تنظیمات

- **پنل مدیریت:** `/admin/`؛ راه‌اندازی ورود و نقش‌ها در [cms-setup.md](docs/cms-setup.md).
- **محتوا** در `src/content/`: واحدها (`units/*.json`)، تنظیمات عمومی، پرسش‌ها، کارگاه‌ها و ریدایرکت‌ها (`settings/*.json`)، مقاله‌ها (`blog/*.md`) و اطلاعیه‌ها (`news/*.md`). `src/data/site.ts` این‌ها را برای صفحه‌ها می‌خواند. مقدار خالی یا `null` یعنی هنوز تأیید نشده؛ در صفحه کادر «در حال تکمیل» نشان داده می‌شود و هیچ مقداری حدسی پر نمی‌شود.
- **تنظیمات ساخت** در فایل `.env` (نمونه با توضیح: `.env.example`): نشانی سایت (`SITE_URL`)، مقصد فرم‌ها و آمار بازدید.
- **فرم‌ها:** تا `PUBLIC_FORM_ENDPOINT` خالی است، فقط خانه‌ها را بررسی می‌کنند و چیزی نمی‌فرستند. گیرنده‌ی PHP برای هاست ایرانی (ذخیره در CSV و خبر در «بله») در `server/` است؛ راهنما: [forms-setup.md](docs/forms-setup.md).

## انتشار و بررسی خودکار

- `.github/workflows/deploy.yml`: بعد از هر تغییر در `main` (و هر روز صبح برای مقاله‌های زمان‌بندی‌شده) سایت را می‌سازد و روی هاست بارگذاری می‌کند. تا متغیر `DEPLOY_TARGET` تنظیم نشده خاموش است.
- `.github/workflows/quality.yml`: روی هر تغییر، ساخت، نقشه‌ی کلمات کلیدی، بررسی همه‌ی صفحه‌ها و Lighthouse موبایل (حداقل ۹۰).
- راهنمای کامل هاست، رمزها و رفع اشکال: [deploy.md](docs/deploy.md).

## به‌روزرسانی بسته‌ها و هشدارهای امنیتی

- نسخه‌ی همه‌ی بسته‌ها دقیق ثابت است (`package.json` و `package-lock.json`)؛ `npm ci` همیشه همان‌ها را نصب می‌کند و دو ساخت پشت‌سرهم از یک محتوا، فایل به فایل یکسان‌اند.
- آبان ۱۴۰۵ Astro از ۵ به ۷ رفت تا هشدارهای امنیتی Astro 5 و کتابخانه‌ی تصویرش بسته شود (از جمله یک مورد «بحرانی»: اجرای کد از راه بهینه‌سازی عکس AVIF). خروجی همه‌ی صفحه‌ها پیش و پس از به‌روزرسانی مقایسه شد: متن، برچسب‌های سئو و ظاهر یکسان بود.
- `npm audit` فقط یک هشدار دارد که هنوز نسخه‌ی اصلاح‌شده ندارد: picomatch ([GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf))، که هنگام ساخت فقط الگوهای نام فایل‌های خود پروژه را می‌خواند و چیزی از آن در سایت منتشرشده نیست. `npm audit fix --force` را اجرا نکنید: Astro را به نسخه‌ی ۵ برمی‌گرداند و هشدارهای جدی برمی‌گردند.
- بعد از هر به‌روزرسانی: `npm run build`، `npm run check:pages` و Lighthouse (بخش ۸ [deploy.md](docs/deploy.md)).

## سیستم طراحی

- زمینه‌ی کاغذی `#fbf9f5`، متن `#17201c`، رنگ اصلی سرمه‌ای لوگو `#01237a`؛ طلایی لوگو `#d9b25a` فقط روی زمینه‌ی سرمه‌ای، و زعفرانی تیره‌تر `#86631a` برای شماره‌ها روی زمینه‌ی روشن. همه‌ی ترکیب‌های متن و زمینه کنتراست WCAG AA دارند. توکن‌ها در `src/styles/global.css`.
- عنوان‌ها با Noto Naskh Arabic و متن با Vazirmatn، روی خود سایت و فقط با حروف فارسی و لاتین لازم (هر خانواده یک فایل حدود ۵۵ تا ۶۰ کیلوبایت؛ `scripts/subset-fonts.py`)؛ وزن‌ها ۴۰۰ تا ۶۰۰.
- جداکننده‌ها خط یک‌پیکسلی‌اند، نه سایه‌ی سنگین.
- حرکت: بلوک‌ها هنگام اسکرول یک بار نرم ظاهر می‌شوند، خط مسیر ۳ تا ۱۸ سالگی با اسکرول پر می‌شود، آیکون‌های Lottie. هر چیزی که خودش پشت سر هم عوض می‌شود دکمه‌ی توقف دارد (نوار کارگاه‌ها، چرخه‌ی واژه‌های بالای صفحه) یا با انتخاب یک مرحله یا رسیدن فوکوس صفحه‌کلید می‌ایستد (مسیر ۳ تا ۱۸ سالگی و چرخه‌ی متد). با «کاهش حرکت» در سیستم‌عامل فقط محو شدن کوتاه می‌ماند و چیزی خودبه‌خود عوض نمی‌شود.
- المان‌های پویا از کاتالوگ 21st.dev (کاغذ شطرنجی تعاملی، خط طلایی دست‌کش، ماژیک تیترها، متنی که با اسکرول پررنگ می‌شود، کارت‌های روی هم، دکمه‌ی مغناطیسی، نوار پیشرفت خواندن، خط زیر پیوندها و منو، نام نوشته‌شده در پانویس) بدون React و با کد خود سایت ساخته شده‌اند؛ منبع، سازنده و مجوز هر کدام در [21st-elements.md](docs/21st-elements.md).
- لوگو از فایل مؤسسه بازسازی شده است (`src/components/Logo.astro` و `public/favicon.svg`).
